## Never publish
- Phone number, home address, personal email (only the Columbia email `@gsb.columbia.edu` is public)
- Grades, salary, visa status, date of birth
- Anything in `private/`: add it to `.gitignore` first
- Confidential deal details beyond the CV's exact wording (client names, values, counterparties)
- Credentials, API keys, tokens, `.env` files
- Anything invented: if it isn't in the CV and Antonio didn't say it, it doesn't go on the site

## Ask me first
- Before any git push or change on GitHub
- Before deleting, renaming or overwriting a file
- Before adding content that isn't in the CV, or reordering CV sections (Education → Experience → Additional Information)

## Style
- Plain HTML and CSS, clean and minimal. No JavaScript, no frameworks, no build step
- Professional but approachable. Columbia blue (`#B9D9EB`) accent, navy (`#0B2545`) text, light background with automatic dark mode
- Streamlined navigation: one sticky top bar with links to each section
- Portfolio as a gallery page that links to each project
- Mobile-friendly, accessible (alt text, contrast, visible focus)
